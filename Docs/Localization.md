# Русский и английский

При первом запуске (включая обновление старого сохранения без языка) игра показывает две кнопки:
«Русский» и «English». Окно блокирует игровой ввод до выбора. После выбора открывается стартовое меню.

Яндекс Игры — исключение: требование 2.14 обязывает определять язык через SDK. Там окно выбора не
показывается: страница берёт `ysdk.environment.i18n.lang` (ru, be, kk, uk, uz → русский, остальные →
английский) и сообщает его игре через `window.nubikPlatformLanguage`; пока SDK отвечает, стартовая
карточка ждёт, чтобы не мелькнуть на другом языке. Если SDK не ответил за 8 секунд или не загрузился,
игрок выбирает сам. Язык, выбранный игроком в настройках (шестерёнка, «Русский» / «English» — требование 6.9),
сохраняется и дальше не перекрывается языком площадки. Касается и `YandexGames`-пакета (`portal.js`), и
шаблона GitHub Pages на домене Яндекса; на GitHub Pages и других порталах язык по-прежнему спрашивается.
В настройках язык меняется сразу, включая уже созданные окна и вывески во дворе.

Выбор хранится в `GameSettings.language` (`ru` / `en`) внутри существующих настроек устройства.
Игровой прогресс и настройки звука, графики и камеры сохраняются. Начало новой игры не сбрасывает язык.
До выбора заголовки загрузчика следуют сохранённому языку страницы или языку браузера;
сам выбор языка игры браузер не пропускает.

Каталог: `Assets/Game/Resources/Localization/English.json` — 396 переводов русских строк и составных
фрагментов. Названия в конфигурации и ключи сохранений не меняются. `LocalizedText` хранит исходную
строку и обновляет видимый перевод при смене языка, в том числе после включения скрытой панели.
Фразы сопоставляются с границами слов, более длинные имеют приоритет. Английское множественное число
для числовых счётчиков отличается от русского. Кэш ограничен 2048 строками.

Все тексты Unity UI создаются через `LocalizedText`, включая WorldSign. Когда текст копируется из
одной подписи в другую, использовать `Localization.Source(label)`, чтобы не потерять русский оригинал.
Добавляя новые русские строки, добавлять соответствующие переводы в каталог.

WebGL: `language.js` переводит заголовок страницы, загрузку, поворот телефона, сообщения об ошибках
и тестовую рекламу GitHub Pages. `NubikLanguage` синхронизирует выбранный язык из Unity в страницу.
Пакетировщик включает `language.js` во все шесть ZIP.

Проверки: `LocalizationTests` проверяет старые настройки, сохранение выбора, весь каталог,
строки баланса, составные подписи и переключение скрытых компонентов. PlayMode проверяет обязательный
первый выбор, все страницы дома и смену языка в открытых настройках. Браузерные кадры —
`TestResults/Localization`; отдельно проверяются мобильная вёрстка и повторное открытие игры.

Обновление WebGL и базы площадок: `ProjectSetup.BuildAllWeb`, затем `Tools/package_platforms.py`.
Языки пакетов отражены в manifest (`languages: ["ru", "en"]`). При отправке в кабинеты площадок
указать оба поддерживаемых языка.
