# Разработка

## Этап 0 — старт проекта, 28 сентября 2026

Выбрана установленная Unity 6000.6.3f1 с Web Build Support. Альтернативная установленная 6000.3.25f1 пока без WebGL-модуля. Версия закреплена; переход на LTS при необходимости делается отдельным изменением после проверки сборки.

Визуальная основа прототипа: тёплая земля, бирюзовый шахтёр, янтарная награда, тёмные панели с контрастными надписями. Крупные подписанные кнопки, отдельные зоны движения и копания. Шрифт Noto Sans встроен в сборку для кириллицы, лицензия SIL OFL находится рядом с файлом шрифта. Это технический прототип; оформление и оригинальная модель из Blender — отдельный этап.

Подготовлены сцена, конфигурация, основная петля и тесты экономики. В точках продажи, покупки, разрушения и рекорда сохраняется единый снимок прогресса. Сохранение локальное; резервная копия может быть на одну транзакцию старее. Нельзя обещать облачную синхронизацию или защиту от очистки данных браузера.

## Следующий этап — плейтест вертикального среза

- Проверить настоящий Android / iPhone, вертикальный и горизонтальный экран, обновление страницы.

## До публикации

- Три зоны до 120 м, пять предметов коллекции, четыре кирки, завершение версии.
- RU/EN, настройки звука, события аналитики без персональных данных.
- SDK: облако с разрешением конфликтов, язык, lifecycle и проверка Game Ready в консоли Яндекса.
- Добровольная реклама и interstitial согласно экономическому документу. Пока рекламных вызовов и платежей нет.
- Проверки ошибок / отказа / повтора callbacks рекламы; идемпотентная выдача бонуса.
- Профилирование памяти / FPS на реальном телефоне, контроль размера распакованной сборки.
- Модерационный чеклист и проверка названия / оригинальности ассетов.

## Результаты проверки

Unity EditMode: 14 тестов, 14 пройдено, 0 ошибок (28 сентября 2026). Проверены недопустимые / повторные блоки, повторная продажа, стоимость и предел кирок, коллекция, сериализация, повреждённое сохранение, будущая версия схемы и доступность первого улучшения.
