# Промо-пролёты

`PromoRecorder` — редакторский инструмент, который рендерит настоящую сцену Unity в RenderTexture 1920 × 1080 при фиксированном шаге 30 кадров/с и передаёт RGB-кадры установленному FFmpeg. Результат: H.264, MP4, yuv420p, CRF 18, без интерфейса, модели инструмента и звука. Частота готового видео не зависит от скорости рендера компьютера.

```powershell
& 'C:\Program Files\Unity\Hub\Editor\6000.6.3f1\Editor\Unity.exe' -batchmode -projectPath 'C:\Users\user\Desktop\noobik' -executeMethod PromoRecorder.RecordAll -promoEncoder 'C:\Users\user\Desktop\ffmpeg-2026-09-28-git-84779ade26-full_build\bin\ffmpeg.exe' -logFile 'C:\Users\user\Desktop\noobik\Logs\promo.log'
```

Не добавлять `-nographics` или `-quit`: нужны графический контекст и работа Play Mode до конца записи. Альтернатива — меню `Nubik / Record 1080p promo`, путь к кодировщику в переменной `NUBIK_FFMPEG`.

Клипы записываются в отдельную папку `Recordings/promo-YYYYMMDD-HHmmss/`:

| Файл | Длительность | Содержание |
|---|---:|---|
| 01_yard.mp4 | 12 с | Двор, дом, заправка, участок |
| 02_descent.mp4 | 16 с | Спуск через биомы к глубине 116 м |
| 03_roots.mp4 | 8 с | Лагерь у корней |
| 04_slate.mp4 | 8 с | Заброшенная штольня |
| 05_crystals.mp4 | 8 с | Кристальный грот |
| 06_magma_meteor.mp4 | 16 с | Лава, метеорит, взрыв и металл внутри |
| 07_cthulhu.mp4 | 26 с | Пробуждение, атаки и выстрелы |
| 08_victory.mp4 | 10 с | Последний удар, погружение босса и возвращение к дому |

Это постановочная съёмка: камера движется по маршруту, шахта заранее раскопана во временном прогрессе, выстрелы босса поставлены по времени. Геометрия, материалы, предупреждения, атаки и анимация смерти берутся из игры. Механики отдельно проверяются PlayMode-тестами.

Для пересъёмки части набора передать `-promoClips 01_yard,06_magma_meteor` и `-promoOutput` с существующей папкой внутри `Recordings/`. Перезаписываются только выбранные клипы. Надписи на вывесках в мире остаются видимы; скрыт именно экранный HUD.

После съёмки выполнить `py -3 Tools/check_recordings.py Recordings/<папка> --ffmpeg <путь-к-ffmpeg.exe>`. Скрипт проверяет разрешение, кодек, количество кадров, длительность, отсутствие аудио и полное декодирование, создаёт полоски контрольных кадров и `validation.json`, а затем соединяет клипы без перекодирования в `Nubik_Promo_FullHD.mp4` (1 минута 44 секунды).

Перед запуском сохраняются обе записи редакторского PlayerPrefs в `editor-save-backup.json`; после выхода из Play Mode они восстанавливаются, рядом появляется `save-restored.txt`. Браузерные сохранения не затрагиваются. При аварийном завершении редактора резервная копия остаётся в папке съёмки для восстановления. `Recordings/` исключён из Git: в коммит попадает инструмент, а не тяжёлые видео.

# Скриншоты локаций 4K

`PromoStills` снимает 14 кадров настоящей сцены на «Ультра»: 3840 × 2160 с 8× MSAA (PNG) и копию 1920 × 1080, усреднённую из 4K блоками 2 × 2 (PNG и JPG 95 %). Интерфейс и лопата скрыты, шахта раскопана во временном прогрессе, как в пролётах; висящая в воздухе руда из раскопа не показывается. Сохранение, настройки редактора и настройки конвейера URP восстанавливаются после съёмки.

```powershell
& 'C:\Program Files\Unity\Hub\Editor\6000.6.3f1\Editor\Unity.exe' -batchmode -projectPath 'C:\Users\user\Desktop\noobik' -executeMethod PromoStills.CaptureAll -stillsOutput 'C:\Users\user\Desktop\noobik\Recordings\stills-YYYYMMDD' -logFile 'C:\Users\user\Desktop\noobik\Logs\stills.log'
```

Без `-nographics`. Отдельные кадры — `-stillsShots 03_yard_pond,14_cthulhu`. Меню: `Nubik / Capture 4K stills`.

| Кадр | Локация |
|---|---|
| 01_yard_overview | Двор целиком: дом, заправка, участок, пруд, будка, грядка |
| 02_yard_house | Дом, патио, дорожка с фонарями |
| 03_yard_pond | Пруд с лягушкой и кувшинками, качели-шина |
| 04_yard_dog_garden | Грядка с пугалом, будка со спящей собакой, заправка |
| 05_shaft_to_the_sky | Вид из шахты вверх на небо |
| 06_house_buyer | Скупка руды в доме |
| 07_house_workshop | Мастерская в доме |
| 08_roots_camp_18m | Лагерь у корней, 18 м |
| 09_old_mine_48m | Старая штольня с вагонеткой, 48 м |
| 10_crystal_grotto_88m | Кристальный грот, 88 м |
| 11_lava_103m | Лавовое озеро, 103 м |
| 12_meteor_114m | Метеорит в кратере, 114 м |
| 13_door_of_seals_120m | Дверь пяти печатей, 120 м |
| 14_cthulhu | Ктулху на арене |

Для просмотра набора: контактный лист 4 × 4 собирается FFmpeg из `1920x1080/*.jpg` (`tile=4x4`). `Recordings/` не попадает в Git.
