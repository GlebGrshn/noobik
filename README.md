# Нубик Шахтёр: копай глубже

Первый прототип Unity для Яндекс Игр. Репозиторий: https://github.com/GlebGrshn/noobik

## Открыть игру

1. Unity Hub → **Add → Add project from disk** → выбрать папку `noobik`.
2. Открыть в **Unity 6000.6.3f1**. Используется URP 17.6.0.
3. Открыть `Assets/Game/Scenes/Mine.unity` и нажать **Play**.
4. Если сцены ещё нет: меню **Nubik → Prepare prototype** создаст её и конфигурацию.

Управление на ПК: клик по экрану захватывает мышь; мышь — осмотр, ЛКМ — копать, WASD — ходить, Shift — бег, пробел — прыжок (держать в воздухе — джетпак), E — скупка / мастерская в доме, F — сканер, Q — аптечка, G — бросить динамит, M — выключить звук (громкость по группам и графика — шестерёнка в паузе или «Настройки» в доме), Esc — пауза (под землёй там же вызов спасателей, там же «Начать игру заново»). Если браузер не даёт захватить мышь, осмотр — с зажатой ПКМ. На телефоне игра только горизонтальная; стик слева (двойной тап и удержание — бег), обзор пальцем справа, кнопки «КОПАТЬ», «ПРЫЖОК» (держать — джетпак), «СКАН», «АПТЕЧКА», «ДИНАМИТ» и меню.

## Что входит в прототип

Языки: русский и английский. При первом запуске появляется выбор «Русский / English»;
поменять язык можно в настройках без перезапуска. Выбор сохраняется на устройстве отдельно
от игрового прогресса. Переведены интерфейс, описания, задания, подсказки, вывески и финал.

- Вид от первого лица: двор с домом, в который можно зайти, и участок 12 × 12 м, который можно раскопать до 120 м.
- Сплошной деформируемый грунт (воксели 0,5 м, сглаженная поверхность), три зоны: земля (0–30 м), камень (30–70 м), пещера с полостями (70–120 м), на дне — зал с запечатанной дверью и финальная панель.
- Нет телепортов. Руда (уголь, медь, железо, серебро, золото, аметист, изумруд, алмаз) и сундуки собираются в рюкзак с ограниченным числом слотов; продаются только у скупщика в доме. Наверх — пешком по уступам или на джетпаке.
- Здоровье: жёсткое приземление ранит, дома и на газоне оно восстанавливается. При потере сознания или вызове спасателей игрок просыпается дома, руда из рюкзака остаётся в шахте, предметы и покупки сохраняются.
- Мастерская в доме: 8 уровней лопаты, 6 уровней рюкзака, джетпак с 5 уровнями топлива, 5 уровней здоровья. Предметы занимают место в рюкзаке: сканер руды (2 слота) и аптечки (1 слот).
- Заказы скупщика на конкретную руду, растущие вместе с прогрессом; семь секретов во дворе и шахте; добровольная реклама за монеты, награда растёт с уровнем снаряжения.
- Альбом из 5 предметов коллекции, свет и туман по глубине, налобный фонарь, частицы, всплывающие суммы и синтезированные звуки.
- Локальное версионированное сохранение v3 с резервной копией и миграцией сохранений v1 и v2.
- WebGL-шаблон, базовые события готовности / геймплея SDK, пауза при потере фокуса.

Это сборка для проверки механики, не версия для модерации. Облачные сохранения, английский язык и аналитика ещё не реализованы, реклама проверена только на локальной заглушке; графика — временные примитивы.

## Настройки и проверка

Баланс: `Assets/Game/Config/MineBalance.asset` — seed, размеры участка, зоны (прочность, виды руды и их веса, свет), руда и сундуки (цена, слоты), уровни лопаты, рюкзака, джетпака и здоровья, предметы, падение и регенерация, коллекция. Менять seed в существующем сохранении нельзя без миграции: прототип сохранит старые данные и откроет временную сессию.

Тесты: **Window → General → Test Runner → EditMode → Run All**. Командная проверка: `Tools/Check.ps1`. Проверяются вместимость рюкзака, повторные выплаты, продажа, прокачка всех линеек, предметы, здоровье, коллекция, сериализация прогресса и грунта, миграции, прочность пород и генерация руды. Звуки пересоздаются командой `py -3 Tools/make_sounds.py`, текстура рельефа породы — `py -3 Tools/make_textures.py`, набор материалов предметов и дома — `py -3 Tools/make_surfaces.py` (затем **Nubik → Prepare prototype** назначит его материалу).

Снимки глубин: PlayMode-тест `DepthSnapshots` запускает сцену, опускает игрока на 12, 45, 90 и 120 м и сохраняет кадры в `TestResults/Snapshots`. Запускать с графикой (без `-nographics`): `Unity.exe -batchmode -projectPath . -runTests -testPlatform PlayMode`. Локальное сохранение редактора на время теста откладывается и восстанавливается.

Проверка WebGL без видимого браузера: запустить сервер сборки и `node Tools/web-check.mjs` — скрипт открывает сборку в headless Edge/Chrome, проходит старт, копание и лавку на ПК, затем телефон вертикально (экран «Поверни телефон») и горизонтально с сенсорным управлением и страницами дома, и сохраняет снимки и ошибки консоли в `TestResults/Web`. Для полного стека исключений есть **Nubik → Build WebGL (development)** → `Builds/WebGL-dev`.

WebGL: установить **Web Build Support** для закреплённой версии Unity и выбрать **Nubik → Build WebGL**. Результат — `Builds/WebGL`, открыть через HTTP, а не `file://`. Пример: `py -3 -m http.server 8080 --directory Builds/WebGL`, затем http://localhost:8080. Для консоли Яндекс Игр упаковывается содержимое этой папки (вместе с `StreamingAssets` — там музыка), с `index.html` в корне архива. Перед загрузкой требуется пройти `Docs/Development.md`.

## Работа с GitHub

Отдельные экспорты для CrazyGames, Poki, GameDistribution, GameMonetize, GamePix и Яндекс Игр:
[инструкции и статус интеграций](Docs/Platforms.md). Сборщик — `Tools/package_platforms.py`,
результат — `Builds/Platforms`, по отдельной папке и ZIP на площадку.

Исходники, `.meta`, сцены, настройки и документы хранятся в Git. `Library`, `Temp`, сборки, логи и личные настройки игнорируются. После завершённого изменения: проверка → осмысленный commit → push. Публичный репозиторий не должен содержать ключей SDK, лицензий Unity и пользовательских сохранений. Blender-файлы добавляем в `Art/Source`, экспорт для Unity — в `Assets/Game/Art`.

Исходные дизайн-документы находятся в `Docs`. Они описывают проект и гипотезы баланса; факт готовности функции отражается в `Docs/Development.md`.
