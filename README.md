# Нубик Шахтёр: копай глубже

Первый прототип Unity для Яндекс Игр. Репозиторий: https://github.com/GlebGrshn/noobik

## Открыть игру

1. Unity Hub → **Add → Add project from disk** → выбрать папку `noobik`.
2. Открыть в **Unity 6000.6.3f1**. Используется URP 17.6.0.
3. Открыть `Assets/Game/Scenes/Mine.unity` и нажать **Play**.
4. Если сцены ещё нет: меню **Nubik → Prepare prototype** создаст её и конфигурацию.

Управление: WASD / стрелки — движение относительно камеры; наведение и удержание ЛКМ — копание. Пробел копает выбранный / ближайший блок. На телефоне — стик, выбор блока касанием и удержание «КОПАТЬ». R / «Наверх» открывает базу. Там можно продать находки, купить кирку и вернуться к месту вылазки.

## Что входит в прототип

- Одна наклонная шахта с условной глубиной 30 м, 150 разрушаемых блоков.
- Временный оригинальный шахтёр из простых форм, камера сверху под углом.
- Видимые золотые находки, монеты, рюкзак и коллекционная каска.
- Две покупки: медная кирка за 60 и стальная за 220 монет.
- Локальное версионированное сохранение с резервной копией.
- WebGL-шаблон, базовые события готовности / геймплея SDK и пауза при потере фокуса.

Это стартовая сборка для проверки механики, не версия для модерации. Реклама, облачные сохранения, английский язык, звук, эффекты, три биома и финал на 120 м ещё не реализованы. Все 150 блоков прототипа находятся в сцене; чанки понадобятся перед расширением мира. Наклонная траншея временно заменяет систему шахтных комнат. HP частично разбитого блока не сохраняется.

## Настройки и проверка

Баланс: `Assets/Game/Config/MineBalance.asset` — seed, награды, прочность, цены и скорость. Менять seed в существующем сохранении нельзя без миграции: прототип сохранит старые данные и откроет временную сессию.

Тесты: **Window → General → Test Runner → EditMode → Run All**. Командная проверка: `Tools/Check.ps1`. Проверяются повторные выплаты, покупка, коллекция, сериализация и достижимость первого улучшения.

WebGL: установить **Web Build Support** для закреплённой версии Unity и выбрать **Nubik → Build WebGL**. Результат — `Builds/WebGL`, открыть через HTTP, а не `file://`. Пример: `py -3 -m http.server 8080 --directory Builds/WebGL`, затем http://localhost:8080. Для консоли Яндекс Игр упаковывается содержимое этой папки, с `index.html` в корне архива. Перед загрузкой требуется пройти `Docs/Development.md`.

## Работа с GitHub

Исходники, `.meta`, сцены, настройки и документы хранятся в Git. `Library`, `Temp`, сборки, логи и личные настройки игнорируются. После завершённого изменения: проверка → осмысленный commit → push. Публичный репозиторий не должен содержать ключей SDK, лицензий Unity и пользовательских сохранений. Blender-файлы добавляем в `Art/Source`, экспорт для Unity — в `Assets/Game/Art`.

Исходные дизайн-документы находятся в `Docs`. Они описывают проект и гипотезы баланса; факт готовности функции отражается в `Docs/Development.md`.
